# Test suite manifest for test/run.sh.
#
# Columns: name|tier|depends|files|modules|description
#
# - tier:       unit (default, fast tier budgeted below 10s once built),
#               extended (slower functional contracts, opt-in), or
#               integration (heavy process/Git fixtures that are opt-in).
# - depends:    comma-separated suite names that must run before this suite.
# - files:      comma-separated test/*.test.sh files; empty for aggregate
#               groups that only express dependencies.
# - modules:    comma-separated source areas this suite covers. `module:<name>`
#               selects every suite that lists <name>.
# - description: one short line without a pipe character.
#
# A test file must appear exactly once across the manifest. test/suites.test.sh
# enforces coverage, unique names, valid dependencies and modules, and the
# absence of cycles so a new test cannot silently fall out of the default tier.
