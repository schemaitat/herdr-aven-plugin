# Test suite manifest for test/run.sh.
#
# Columns: name|tier|depends|files|description
#
# - tier:       unit (default, budgeted below 20s once built) or integration
#               (heavy process/Git fixtures that are opt-in).
# - depends:    comma-separated suite names that must run before this suite.
# - files:      comma-separated test/*.test.sh files; empty for aggregate
#               groups that only express dependencies.
# - description: one short line without a pipe character.
#
# A test file must appear exactly once across the manifest. test/suites.test.sh
# enforces coverage, unique names, valid dependencies and the absence of cycles
# so a new test cannot silently fall out of the default tier.
